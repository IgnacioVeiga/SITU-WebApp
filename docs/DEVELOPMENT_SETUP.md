# Frontend Development Setup

Standard onboarding guide for `SITU-Frontend`.

## 1. Prerequisites

- Node.js LTS
- npm
- Optional: VS Code

## 2. Install dependencies

```bash
npm install
```

## 3. Run by environment

```bash
npm run start:dev
npm run start:qa
npm run start:mock
npm run start:prod
```

## 4. Build

```bash
npm run build
npm run build:dev
npm run build:qa
npm run build:mock
npm run build:prod
```

## 5. Test

```bash
npm run test
npm run test:ci
```
